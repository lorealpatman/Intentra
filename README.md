# Intentra Backend

Backend API for Intentra - an intentional connection app that encourages meaningful communication.

## Features
- User authentication with JWT
- Unique 6-character connection codes
- Daily message limits (5 per user per connection)
- Connection unlock after genuine relationship forms
- Real-time messaging with Socket.io
- Push notification support

## Tech Stack
- Node.js + Express
- MongoDB (Mongoose)
- Socket.io
- Firebase Cloud Messaging
- JWT Authentication

## Setup
1. Clone repository
2. `npm install`
3. Create `.env` file (see `.env.example`)
4. `npm run dev`

## Environment Variables
See `.env.example` for required variables.
